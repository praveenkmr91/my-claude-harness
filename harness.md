# Harness maintenance

Injected by `hooks/harness-context.sh` once per session, on the first Write/Edit under `~/.claude/` or of any `CLAUDE.md` / `CLAUDE.local.md` / `.claude/` path, or a write-shaped Bash command naming `~/.claude` (`projects/` memory and `plans/` excluded). The once-flag is per session, so a subagent editing after the parent triggered never sees it — the dispatcher owns the verify gate.

## Maintenance
- **Harness tests: `node --test ~/.claude/tests/*.test.js` after any edit to CLAUDE.md, a rule doc, a hook, or settings hooks.** Checks pointers resolve, frontmatter, hook syntax, rule↔hook agreement, always-load word ceilings (`tests/budget-baseline.json`), and duplicated sentences across rule docs. Red = fix the drift or raise the baseline deliberately, never allowlist.
- **One tier owns a rule.** Layered config (global CLAUDE.md → framework ref → project memory): general principle lives in exactly one tier; others hold pointer or specific instance. Promote/demote = move + pointer, never copy.
- **Hydrogen guidance is repo-gated — never add unconditional Hydrogen rules here.** `hydrogen.md` loads only via a Hydrogen repo's `CLAUDE.local.md` import; `hooks/hydrogen-context.sh` and `hooks/hydrogen-util-guard.sh` exit unless the toplevel `package.json` depends on `@additiv-hydrogen`.
- **Hook output channels: plain stdout never reaches the model.** Only exit 2 + stderr (blocking) or JSON `hookSpecificOutput.additionalContext` (advisory) does — a stdout-printing PostToolUse hook runs silently for months. **`if` gates the process spawn per subcommand** (`a && b` matched separately); a script guarding several command families needs one `if` entry per family, or the unlisted families never run.
- **Write|Edit hooks are blind to shell writes, so `hooks/bash-write-guard.js` blocks them.** Heredoc, redirect, `tee`, inline-interpreter and staged-in-scratch-then-copied writes to source, config or doc files are denied; `sed -i`, `git mv`, `.bak` restores and temp-dir output pass, except on a plan file (a `.md` directly inside any `plans/` directory), which only Write or Edit may change so `hooks/plan-lint.js` sees it. `tests/bash-write-guard.test.js` holds the discriminating cases — replay real transcripts through the hook before loosening a pattern. A new file-quality hook goes on `Write|Edit` and relies on this guard, never on parsing Bash itself.
- **Plugin curation record = `~/.claude/plugin-curation.md`** — read before touching `enabledPlugins`, and before localizing a skill (a tombstoned plugin's cache may already hold a curated copy); `false` entries are deliberate tombstones, curation reverts on plugin updates, usage oracle = transcripts not name-greps.
- **Weekly audit = `automation/weekly-audit.sh`, fired Mondays 09:00 by `automation/com.praveen.weekly-audit.plist`.** Repos are the plist's trailing arguments; each run writes its report and logs to `state/audits/<repo>/` only, and `hooks/audit-due.sh` copies the newest report over `<repo>/docs/audits/audit.md` at the next session start or resume there (git history is the week-by-week trail; committed by hand). Never grant `/bin/bash` Full Disk Access to let the run write the repo itself. Install or reload: `cp` the plist to `~/Library/LaunchAgents/`, then `launchctl bootout` + `bootstrap gui/$(id -u)`. Read-only rests on the script's `--disallowedTools` list — never trim it.
- **Context canary = `automation/context-canary.sh`, run Mondays at the end of `weekly-audit.sh` (catches Claude Code updates) and by hand after changing how a hook emits output or which file a hook or always-load doc injects.** Fresh haiku sessions answer one question per delivery channel, with a user-settings-off rerun as control; anything but PASS or STALE exits 1. About $0.15 a run, so never in `node --test`. A new probe's question must not contain its expected string.
- **Opt-in gates key on my proposal plus his yes, never on him naming the thing.** Praveen rarely invokes an escalation by name; a hook or rule that waits for the word never fires. Read the approval as his yes to a reply carrying a reserved proposal phrase, never to one that merely mentions the thing (`enforce-subagent-model.sh` keys on `Fable review?` / `Fable battery?`).
- **Parked harness work = `~/.claude/harness-backlog.md`.** Measured friction not fixed yet, each entry with its evidence and fix; an entry leaves the file in the commit that fixes it.

## Figma MCP
- **Figma MCP `download_assets`: commit the `export`, never `svgAssets`.** `svgAssets` drops instance transforms — a rotated or flipped instance comes back wrong and nothing downstream can tell. `export` (`defaultFormat: "svg"`) is the whole-node render (frame, offset, rotation, background rects to strip); it is `null` and `get_metadata` says "invalid node selection" unless the node's page is open in Figma desktop.
